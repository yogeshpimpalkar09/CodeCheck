# CodeSaathi

CodeSaathi is a beginner-friendly coding-error explainer for students in India. It turns common programming errors into simple English or Hindi explanations, then suggests clear ways to fix them.

## The problem

Coding errors can feel intimidating, especially when error messages use unfamiliar technical language. New learners often do not know where to look or what to try next.

## The solution

Users can paste an error message, code, or both. CodeSaathi provides:

- Simple English or Hindi explanations
- A likely error line with a visual arrow
- Step-by-step fixes for common mistakes
- Suggested corrected code for clear syntax errors
- A simpler example for learners who need extra help

## Built with

- HTML
- CSS
- JavaScript
- OpenAI Codex, used for planning, building, testing, and improving the project

## Run locally

Open `index.html` in a modern web browser.

## Safety

CodeSaathi runs in the browser. Do not paste passwords, API keys, or other secrets into the app.
